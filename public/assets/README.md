# Wildlife Photography Website Assets

This folder contains image assets used throughout the Wildlife Photography website.

Note: For the actual website deployment, this directory would contain original photographs taken by Upul Dunuhinga. Currently, we're using placeholder images from Pexels.com for demonstration purposes.

## Image Categories

The website uses images across several categories:
- Wildlife (elephants, leopards, birds, reptiles)
- Landscapes (national parks, natural scenery)
- Photographer portraits
- Safari and workshop activities

## Image Usage Guidelines

- Always provide appropriate alt text for accessibility
- Optimize images for web delivery
- Respect copyright and attribution requirements
- Use responsive image techniques for optimal display across devices
